# gpr-poc/data — frozen inputs for the QGI-GPR PoC validation

These two small files are vendored so the PoC validation
(`../validate_gpr_poc.py`) reproduces from a clean checkout. This is a
deliberate, scoped exception to the qgi-ml "data lives in S3, not git" rule
(which targets large S3 training sets): a 2.9 MB frozen fixture for a result
that justifies a multi-week flagship build is worth freezing in-repo.

## `gpr_export.xls` (2.7 MB) — the answer key
- **Source:** Caldara, Dario & Matteo Iacoviello, "Measuring Geopolitical
  Risk," *American Economic Review* 2022, 112(4):1194–1225.
- **Download:** https://www.matteoiacoviello.com/gpr_files/data_gpr_export.xls
- **License:** CC-BY (free to redistribute with attribution; attribution above).
- **Shape:** single sheet, 1518×115. Monthly. Columns include the global GPR
  variants, `SHAREH_CAT_1..8` (the 8 categories), and 44 `GPRC_<ISO3>` country
  columns (the per-country GPR; values are percent-of-articles).
- **Refresh:** this is the production T1.2 "GPR auto-download" input. Re-fetch
  the URL to update; the PoC pins the version committed here.

## `topic_monthly.csv` (170 KB) — the proxy input
- **Source:** QGI GDELT PoC roll-up (`qgi-gdelt-poc`). Monthly GDELT GKG
  document counts per country for the 14 QGI Topics + `total_docs` + `avg_tone`.
  `country_code` is FIPS 2-letter (e.g. TS=Tunisia, BM=Myanmar), NOT ISO2.
- **Not** the raw GDELT corpus (which is never committed) — this is a small
  derived monthly aggregate.
- **Refresh:** regenerated by the GDELT roll-up; the production build reads the
  owned `qgi_gdelt.gkg_topic_flags` table instead (see the build plan).

Provenance, method, and the locked category→topic mapping:
`../gpr-theme-dictionary.json`. Result + recommendation:
`qgi-docs/internal/roadmap/qgi-gpr-poc-validation.md`.
