# QGI Country Events Dataset

Generated by Claude (Haiku/Sonnet) for Recipe matching in the knowledge extraction pipeline.

## Status
- Initial generation: ~20-30 events per country (sparse — needs enrichment)
- Target: ~5-10 events per country per year (1950-2025)
- Generation approach: one country × one decade per LLM call for density

## Schema
```json
{
  "country": "string — must match countries table name_1",
  "year": "int — 1950-2025",
  "title": "string — max 10 words",
  "description": "string — 1-2 sentences",
  "category": "string — free text (to be clustered later)"
}
```

## Files
- `batches/` — raw generation output (JSON per batch)
- `countries_100.json` — target country list (114 countries)
- `consolidated.json` — merged + validated (created after generation)

## Enrichment plan
Run decade-per-country calls to fill gaps. Priority countries:
major conflict zones, G20 nations, countries with most patterns in legacy data.
